# Describing things

This chapter is about the facts you record on your kinds. You learn the difference between a value and a link, how a fact on one kind reaches the kinds below it, how to put rules on a fact, and how to read one link from both ends. Read it once you have some classes.

## What you should know

- A [class](../GLOSSARY.md#concept-class) is a kind of thing, and an [instance](../GLOSSARY.md#concept-instance) is one real example of it.
- A [class hierarchy](../GLOSSARY.md#concept-class-hierarchy) stacks classes with "is a kind of" links, so a class sits below its parents.
- A [slot](../GLOSSARY.md#concept-slot) is a named field you can fill in for a kind of thing. The first page here defines it again.

## The pages

- [Properties or relationships?](properties-and-relationships.md) answers whether a fact is a plain value or a link to another thing.
- [What is slot inheritance?](slot-inheritance.md) answers where to attach a fact so every kind below gets it.
- [What are facets?](facets.md) answers how to restrict the values a fact may hold.
- [What is an inverse relationship?](inverse-relationships.md) answers how to state a link once and read it from both ends.
