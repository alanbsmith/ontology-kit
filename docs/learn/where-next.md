# Where next

You can now explain what a knowledge graph and an ontology are, and write the questions yours must answer. You can tell a class from an instance, stack classes, and keep sibling kinds from overlapping. You can choose between a value and a link, attach a slot once and let it flow down, and put rules on it. And you can read a finding from `okb validate`, fix it or explain it, and trace the rule to its source.

## What to do now

- **Build one.** The [Quickstart](../getting-started/quickstart.md) takes about five minutes. The [wine](../../examples/wine/tutorial/0-intro.md) and [espresso](../../examples/espresso/tutorial/0-intro.md) tutorials build a whole ontology step by step.
- **Pick a way to build.** [Build](../build/index.md) compares working with Claude, with the CLI, and from your existing docs.
- **Look things up.** The [Reference](../GLOSSARY.md) holds the glossary, every rule, the decision guides and the CLI commands.

If you want to read a chapter again, start at the [overview](index.md).
