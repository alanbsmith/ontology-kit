# The big picture

This chapter shows what you're building and why. You learn what a knowledge graph is, how an ontology keeps one consistent, and why you write questions before you model anything. It relies on nothing else in the course, so start here if you're new.

## What you should know

Nothing. If you've used a database, a table definition is the closest idea to an ontology.

## The pages

- [What is a knowledge graph?](knowledge-graphs.md) answers how facts become things joined by named links.
- [What is an ontology?](ontologies.md) answers what keeps those links consistent, and how a plan differs from the data.
- [Why start with questions?](competency-questions.md) answers how to decide what your graph needs to cover.
