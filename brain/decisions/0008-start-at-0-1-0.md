# 0008: Start at 0.1.0

**Decision:** the packages start at 0.1.0. Before 1.0, any release may change the CLI, the format or the format API, and the changelog says what did.

**Why:** 1.0.0 would read as stable before anything had been used. 1.0 waits for a CLI that has gone a while without renames, a documented format upgrade path, an outside tool on `@ontology-kit/format`, and a few clean releases through the workflow.
