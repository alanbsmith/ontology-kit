# 0030: An evaluation runner for goal 6

**Decision:** goal 6 of [0021](0021-one-point-zero-is-six-user-goals.md) means an evaluation runner can connect a model, the eval questions and the knowledge base, so it has everything it needs to test an agent. The first runner is the owner's own eval-kit (private for now). The plan and issues call it "an evaluation runner".

**Why:** the owner's goal for their evaluation runner. A generic name avoids confusion while the project is private, and keeps okb from depending on one runner.

**Consequences:** okb's part is open: see [open-questions.md](../open-questions.md).
