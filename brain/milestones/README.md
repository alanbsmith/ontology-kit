# Milestones

One file per milestone that's active or next. Each holds what the board can't: why the milestone exists, why it comes now, decisions made inside it, and lessons from its sessions. Its issues stay on the board and its GitHub milestone.

A file has four sections: **Why**, **Why now**, **Done when**, and **Log**. The log is dated one-line entries, newest last, added at the end of each session. When a milestone closes, add a last log line and move anything still undecided to [open-questions.md](../open-questions.md).
