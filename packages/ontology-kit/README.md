# ontology-kit

This package installs the `okb` command from [Ontology Kit](https://ontology-kit.dev). It only depends on [`@ontology-kit/okb`](https://www.npmjs.com/package/@ontology-kit/okb), which holds the code, and the two are released together with the same version.

Needs **Node.js 24+**.

```bash
npx ontology-kit version
npm install --global ontology-kit
okb init my-ontology
```

**Docs: [ontology-kit.dev](https://ontology-kit.dev)**. The source is at [github.com/alanbsmith/ontology-kit](https://github.com/alanbsmith/ontology-kit).
