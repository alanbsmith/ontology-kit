# Ontology Kit

A toolkit that walks a beginner through building their first ontology, following the method in **Ontology Development 101** (Noy & McGuinness, 2001). It has a meta-KB of the method and its rules, an `okb` command-line tool that guides and checks your work, and skills that let Claude coach you.

**Docs: [ontology-kit.dev](https://ontology-kit.dev)**

## Install

Needs **Node.js 24+**.

```bash
git clone https://github.com/alanbsmith/ontology-kit
cd ontology-kit
npm install
npm link
```

Then `okb init my-ontology` starts one. See the [introduction](https://ontology-kit.dev/getting-started/) and the [installation guide](https://ontology-kit.dev/getting-started/installation/), and [CONTRIBUTING.md](CONTRIBUTING.md) to work on the kit itself.
